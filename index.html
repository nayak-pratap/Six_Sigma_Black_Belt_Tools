One project, charter to closure

DMAIC Project Workbook

The pages below are each useful on their own, but a real project is a chain: the gauge study decides whether the baseline can be trusted, the baseline points at what to investigate, the regression picks the factors for the experiment, and the experiment predicts the result the pilot then confirms. The workbook carries one carbide-insert project through all eight stages on a single dataset, with gates that stop the project when the evidence will not support the next step. Each stage links to the pages here so you can run the same step on your own numbers.
