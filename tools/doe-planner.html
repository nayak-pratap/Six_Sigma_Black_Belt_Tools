DOE Run Table Planner

Build a randomised run table for a 2-level full or half-fraction factorial, with replicates and centre points, and see what is aliased.

A full 2ᵏ runs every combination. A half fraction (2ᵏ⁻¹) runs half of them, with the last factor set to the product of the others (generator I = ABC…): fewer runs, but effects are confounded. Randomise run order to protect against drift; add centre points to detect curvature. Example: a 2³ study of sintering temperature, press pressure and hold time with two replicates.
