Pugh Concept Selection Matrix

Compare solution or design concepts against a baseline on weighted criteria and see which concept wins and where it is weak.

Score each concept against a fixed baseline: +1 better, 0 same, −1 worse. Weighted score = Σ weight × score. The matrix surfaces strengths and weaknesses; the winner is often a hybrid that borrows the best features of the others. Example: three ways to reduce chipping versus the current process.
