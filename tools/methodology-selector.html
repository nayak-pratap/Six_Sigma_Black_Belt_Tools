Which Methodology? Project Type Selector

Answer five questions to choose between a quick fix, project management, Lean, DMAIC or DFSS, with the reason and first move.

This follows the logic of the project-type decision flow in the Black Belt pocket guide: first decide whether the work is a project at all, then whether the cause or the solution is known, then whether the problem is waste, variation or design. Example: an existing process with an unknown cause and inconsistent results leads to DMAIC.
