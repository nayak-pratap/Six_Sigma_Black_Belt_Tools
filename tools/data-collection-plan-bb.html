Operational Definitions and Data Collection Plan

Write each measure so two people would collect it identically, and check the plan for the gaps that ruin data.

For each measure give the operational definition (what counts, how, with which instrument), sampling, who and when. A measure is only usable when two people would record the same value. Example: measures for a chipping study.
