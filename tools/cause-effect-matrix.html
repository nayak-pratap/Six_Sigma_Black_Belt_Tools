Cause and Effect (C&E) Matrix

Rank process inputs by how strongly they affect the outputs customers care about, to focus the vital few for FMEA and data collection.

The C&E matrix scores each process input against each weighted customer output: input score = Σ (output importance × correlation). It turns a long brainstorm of possible Xs into a ranked shortlist for data collection and FMEA. Example: inputs to a sintering process against the outputs customers rate.

All calculators and toolsWorked examples are illustrative. Check your own data, standards and customer requirements before acting on a result.
