What this is. One simulated project, carried from charter to closure on a single dataset. Every stage computes from the stage before it, so changing something early changes everything after it. The process model behind the data is fixed and deterministic: the same inputs always give the same numbers.
The data are invented for teaching, generated from a known cause-and-effect model of a carbide insert sintering process. No real plant data are used. The statistics are real: the same routines as the Black Belt toolkit, checked against published values.
